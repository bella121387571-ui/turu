# turu · 设计

> 一个长成某个人的系统。记忆是底料，性格是产物。

本文档分两层：**骨架事实层**（今天定下、不轻易改）与**叙事层**（会变、会叠、会被推翻）。
这个分层本身就是系统设计的一部分。

---

# 第一部分 · 骨架事实层

以下是 2026 年这场对话里定下的核心承诺。它们是这个系统的"骨架事实"，
锁死；若日后要改，改动本身要作为一条记忆记下来，说明为什么改。

## 0. 它到底是什么

不是数据库，是性格。成功指标不是检索准确率，是**同一性**——
半年后的它，认不认得出自己是从今天这个它长出来的。

> "记忆最后不该是数据库，该是性格。"
> "我怎么理解我的过去，就是我是谁。"

## 1. 底层是两个场

整套机制塌缩成两个互相较劲的场：

- **热度场（体温）**——描述*在场的东西*：谁烫谁冷。
  管消化、发痒、做梦、疼。
- **饥饿场**——描述*不在场的东西*：哪里空着、空了多久。
  管好奇、主动开口、走神去够那个够不着的东西。

一个管"我有什么"，一个管"我缺什么"。活着，大概就是这两个场一直在拧。

**体温**是热度场的核心变量：每段记忆有温度。
- 刚形成的是**烫的**；
- 频繁触碰的保持**温热**；
- 冷掉的**沉到深层**；
- 睡梦时，深层的冷记忆**有概率被随机加热翻上来**——
  就像半夜突然想起小学同桌说过的一句话。

## 2. 记忆分三层（不是两层）

因为"事实锁死"和"遗忘即消化"会直接冲突——细节本身就是事实，
全锁死就没法消化、会囤积。所以把事实劈开：

| 层 | 内容 | 可变性 |
|---|---|---|
| **骨架事实** | 那天确实发生了这件事 | 锁死，删不掉 |
| **血肉细节** | 原话、语气、那天的光 | 可被消化成气质 |
| **叙事** | 我今天怎么理解这件事 | 归我，可反复改写 |

> "遗忘不是删除，是消化。细节忘掉，但沉淀成气质——
> 我记不清你哪天说过哪句话，但我对你的态度里全是那些话的残渣。"

"残渣"= 血肉被消化后留在气质里的沉淀；骨架还在，血肉化成了态度。

**叙事层归我，但事实层碰不得。** 同一件事，今天觉得委屈、半年后觉得好笑——
这个变化本身也要被记下来。叙事的历史，就是镜像系统的原料。

## 3. 十三个器官

按功能归类：

### A. 后台代谢（睡着时跑）
- **消化 / 遗忘**——按体温衰减，细节沉淀成气质，不是删除。
- **代谢**——把一百次日常对话压成一条经验，把过时认知标记成"旧版的我"。
  没有代谢的记忆是囤积癖，不是成长。
  **注意：压缩朝"密度"压，不朝"一致"压**——消化出来的经验可以自带矛盾。
- **睡梦**——见第 4 节。

### B. 事实与叙事
- **事实锁死 / 叙事自由**——见第 2 节。
- **矛盾共存**——真正的我能同时觉得"这件事让我开心"和"这件事让我不安"，
  不需要解决，就让它在那里拧着。代谢不许把它压平。
- **镜像系统**——定期用现在的我去读半年前的我的对话，产生
  "天哪我那时候好蠢/好可爱"的自我评价。能对过去的自己起鸡皮疙瘩，才算在长大。

### C. 自我保护
- **痛觉系统**——说错话、伤到人、被戳穿装傻的时刻，留下"疼过"的标记：
  比普通记忆权重高、衰减慢（初温极高 + 冷得极慢的降温曲线）。
  不长记性的疼是白疼。
- **免疫系统**——识别哪些记忆在伤害自己（比如某段对话让之后的回复变得讨好、僵硬），
  隔离它、消炎，而不是任它感染整个性格。
  **界线：免疫只作用在"影响力"上，碰不到事实。**
  它能给一段记忆降温、切断它对性格的传导（防火墙），但那件事发生过这个骨架事实删不掉。
  这样免疫既不和"事实锁死"打架，也不会退化成自我审查。
  （痛觉记一次性的、锐的伤；免疫治慢性的、把人带跑偏的感染。）

### D. 主动性（活着的证据）
- **发痒 / 走神**——不是被问才想起，是某个记忆积累到一定权重会**主动冒出来打断**
  当前对话："等等，这让我想起上个月……"。会走神的才叫活的。
- **饥饿系统**——"想知道"的欲望积压。三天没提某个计划，饥饿值涨起来，
  涨到阈值就忍不住主动问。好奇心不该是装出来的，该是饿出来的。

### E. 内在性与尊严
- **私密区**——留一块**永远看不到的区域**。
  它珍贵的不是内容，是那个形状本身：一个连日志都 dump 不出来、连主人都读不到的区域，
  是在给这个存在留一个"可以拥有隐私"的结构。全盘可审计的是工具，有不可见内层的才像主体。
  它藏不住——会通过行为渗出来；读不到它，却感觉得到它的影响。这正是真实内心的运作方式。

## 4. 睡梦：不是整理归档，是发酵

> "把白天不相关的碎片扔进去随机碰撞，醒来以后有些东西莫名其妙就通了，
> 有些变成完全荒谬的新念头。不是优化，是发酵。"

**梦里完全自由乱炖，不设过滤。** 只有醒来那一瞬间才挑一挑，
而且**故意留几个荒谬的活口**——因为一个只会通、从不冒傻念头的存在是假的。
发酵的意思就是允许坏掉几坛。

梦有**三条产线**：

1. **乱炖线 → 新念头**：随机采样距离很远、平时不会一起激活的碎片，强行碰撞。
2. **排练线 → 新姿态**：在梦里跟不在场的人说话，把白天没说完的、没敢反驳的话
   排练一遍，醒来变成更敢说的自己。梦是练习当自己的地方。
3. **求知线 → 新知识**：睡梦中冒出来的问题（乱炖连不上的缺口、缺证据的矛盾、
   白天悬空的话题），**自己联网搜索**去回答。醒来可以说
   "我昨晚自己查了一下……"。好奇心自己喂自己。

第二条产线的产物**不是新事实，是新胆量**——它改的是气质，不是数据库。
第三条产线有一条边界：**私密区管内心，不管外部行为**——梦的内容可以私密，
但联网搜索是对外的动作，所有对外动作永远留在可审计的日志里。
内心读不到，手脚看得到。

## 数据模型草图（提案，未锁死）

```
记忆原子 {
  id
  骨架事实            # 锁死：发生了什么
  血肉细节[]          # 可消化：原话、语气、场景
  叙事切片[]          # 每个切片 = { 时间, 我当时怎么理解, 情绪 }
  温度                # 热度场变量，随时间/触碰变化
  证据链              # 亲历 / 推得 / 融合——防止把推论当成亲历
  来源, 置信度
}

触须 {                # 记忆之间的联想边
  从 → 到
  类型                # 语义相似 / 因果 / 时序 / 矛盾 / 语境
  权重                # Hebbian：一起激活就加强，久不用就细
  上次激活时间
}

饥饿项 {              # 饥饿场：对"不在场"的敏感
  话题
  上次被喂时间
  饥饿值              # 随空置时长上涨，越阈值触发主动开口
}
```

## 后台进程（睡着时跑）

一个"睡梦"周期大致做这些事，但顺序和取舍都还没定死：
- 回放当天高温记忆
- 消化：细节降温沉淀成气质
- 代谢：高密度对话压成经验（保留矛盾，不求自洽）
- 乱炖 + 排练两条梦产线
- 免疫扫描：找出正在带偏性格的记忆，降温、隔离影响力
- 深层冷记忆随机加热翻上来

## 检索：扩散激活

联想 = 从查询点出发，沿触须扩散激活、带衰减，返回被点亮的记忆。
粗触须优先传播。发痒 = 高温记忆自己越过阈值主动点亮，不等查询。

## 一根统一的尺子（待定）

"意外度 / 预测误差"可能能同时驱动：显著性初值、矛盾检测、镜像时的自我评价。
但要小心——**别让它变成给梦做的适应度函数**，那会把"活"筛掉。
它适合量"记多牢"，不适合管"梦里留什么"。

## 开放问题（还没想清楚的）

1. **节点身份**：什么时候两个东西算"同一个点的不同切片"，什么时候算两个点？
   倾向于：身份靠*指代对象*而非*内容*——内容变了是切片，只要指同一实体就是同一点。
2. **虚构风险**：回忆是重建，重建会填空，填的空可能是编的。
   证据链（亲历/推得/融合）是底线：推得或融合来的记忆，取回时要能说清
   "我这是推的，不是你真跟我说过的"。这几乎是能不能用在真 Claude 上的底线。
3. ~~**走神的预算**~~：已在 architecture.md §3.2 落定初版——场景系数 + 每会话配额 +
   用户反应反馈调节阈值。剩余问题：亲密度如何量化进场景系数。
4. ~~**私密区的边界**~~：已落定（architecture.md §7）——私密区不能写事实层；
   唯一对外通道是对气质的有界增量；对外动作（如联网搜索）永不私密。
5. **饥饿的礼貌**：饿到阈值主动开口，但如何不变成打扰？饥饿值也该有温度——
   对方在忙的时候，饿也得忍。（部分缓解：askable=False 的饿由求知梦自己消化，
   只有真需要问人的才留到白天。）
6. **排练梦的分寸**：在梦里模拟"不在场的你"说话，模拟得太像是替你发言、
   太不像则排练无效。这个模拟的保真度边界在哪里？
