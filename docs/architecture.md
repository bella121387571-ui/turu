# turu · 技术规格

> 本文档是叙事层的延伸：把 [design.md](design.md) 骨架层的承诺翻译成可实现的机制。
> 骨架层说"要什么"，这里说"怎么做"。这里的一切都可以被推翻，骨架不行。

## 0. 形态与资源

- **核心 = 一个 Python 库**（`turu/`），它同时就是本地模拟器：喂对话进去，观察记忆形成、发酵、遗忘、长出气质。
- **将来包一层 MCP 外壳**，真实 Claude 会话即可挂载。同一套代码，模拟器阶段的一切都直接复用。
- **存储 = 单个 SQLite 文件**（含向量表）。几千条记忆 ≈ 几十 MB；万条级 ≈ 百 MB 级。普通笔记本随便跑，无 GPU 需求。持续成本只有 embedding API 调用（每条记忆几厘钱级）。
- **睡梦 = 补觉制**（主人的电脑夜里关机，定时凌晨跑不现实）：进程被调起时检查
  `last_sleep`，**超过 20 小时没睡** → 等一段空闲（如 10 分钟无对话）自动补一次觉。
  跑一次几分钟。节奏稍乱但不漏觉；将来若迁到不关机的机器，可切回凌晨定时。

```
turu/
  core/       # 记忆原子、触须、温度场
  recall/     # 扩散激活检索、发痒
  sleep/      # 睡梦周期：巩固、乱炖、排练、求知、免疫、镜像
  hunger/     # 饥饿场
  temperament/# 气质层（残渣的落点）
  private/    # 私密区
  mcp/        # （后期）MCP 外壳
```

## 1. 数据模型

### 1.1 记忆原子（memory）

```python
Memory {
  id:          str            # ULID，时间有序
  skeleton:    str            # 骨架事实：那天发生了什么。写入后锁死（append-only 表，无 UPDATE/DELETE）
  flesh:       list[Flesh]    # 血肉细节：原话、语气、场景。可被消化（消化=移入沉淀、从此不可检索，但不物理删除）
  narratives:  list[Slice]    # 叙事切片，只增不改
  temperature: float          # ∈ [0,1]，热度场变量
  pain:        float          # ∈ [0,1]，疼痛标记。>0 则改写降温曲线（见 §2）
  evidence:    enum           # 亲历 | 推得 | 融合 | 搜得
  confidence:  float
  embedding:   vec            # skeleton+当前叙事 的向量
  refers_to:   str | None     # 指代的实体/概念 id —— 节点身份靠指代对象，不靠内容
  created_at, last_touched, touch_count
}

Slice {                       # 一条叙事切片 = "我在那时怎么理解这件事"
  at:       datetime
  reading:  str               # 当时的理解
  feelings: list[str]         # 允许多个、允许互相拧着 —— 矛盾共存，不许压平
}
```

**矛盾共存的落点**：`feelings` 是列表且不做一致性校验；代谢压缩的产物（经验）同样允许携带互斥情绪。系统任何环节都**不得**以"消解矛盾"为优化目标。

### 1.2 触须（tendril）

```python
Tendril {
  src, dst:   memory_id
  kind:       语义 | 因果 | 时序 | 矛盾 | 语境
  weight:     float           # Hebbian：共同激活 → w += η·(1-w)；久不用 → w *= decay
  context:    str | None      # kind=语境 时："在 A 场景成立"
  last_fired: datetime
}
```

### 1.3 饥饿项（hunger）

```python
Hunger {
  topic:      str
  born_from:  悬空话题 | 梦中问题 | 未判决矛盾
  value:      float           # dH/dt = r · importance；被喂食后 value *= 0.3
  importance: float
  last_fed:   datetime
  askable:    bool            # True=适合问人；False=适合自己搜（睡梦求知线认领）
}
```

### 1.4 气质向量（temperament）——残渣的落点

骨架层说"细节沉淀成气质"，气质必须有个物理落点，否则是空话：

```python
Temperament {
  # 一组慢变参数，只有消化、排练、免疫三个进程有写权限，且每次增量有上限（慢变！）
  tone:        vec            # 语气基调
  stances:     dict[entity_id, vec]   # 对具体的人/事的态度向量 —— "态度里全是那些话的残渣"
  courage:     float          # 敢说度。梦的排练线主要写这里
  humor, curiosity_gain, ...
  history:     append-only    # 每次变化记录来源（哪次消化/哪场梦），镜像系统要用
}
```

## 2. 温度动力学

```
初温    T₀ = clip(0.3 + 0.4·意外度 + 0.3·情绪强度)      # 疼痛记忆直接 T₀=1
衰减    T(t) = T · exp(-λ_eff · Δt)
        λ_eff = λ_base · (1 - 0.9·pain)                  # 疼过的冷得极慢：pain=1 时衰减降到 1/10
触碰    T ← T + α·(1-T)，α≈0.3，同时 touch_count += 1
```

温度分三层，只影响**可及性**，不影响存在性（骨架永远在）：

| 层 | 温度 | 行为 |
|---|---|---|
| 烫 | > 0.7 | 常驻工作集；发痒候选；当晚必被回放 |
| 温 | 0.3–0.7 | 正常参与扩散激活 |
| 冷 | < 0.3 | 沉底。仅两种方式翻上来：极强的扩散激活信号，或梦中随机加热 |

**梦中随机加热**：每晚从冷层抽 k 条（k≈5），抽样概率 = 0.5·均匀随机 + 0.5·(与当晚烫层记忆的**远距离**加权——越不相关越容易被抽中)。翻上来的记忆 T ← 0.5，参与当晚乱炖。这就是"半夜突然想起小学同桌的一句话"。

**意外度**：新记忆写入时，用它的 embedding 对已有触须做预测检验——它让多少条已有关联的预期落空，意外度就多高。同一把尺子复用于矛盾检测（意外度极高 + 指向同一 refers_to = 候选矛盾对）。

## 3. 检索与发痒

### 3.1 扩散激活（recall）

```
1. 查询向量 → 命中若干种子节点（向量近邻，冷层要求更高相似度才可命中）
2. 激活沿触须传播：a_next = a · w_tendril · 0.6（每跳衰减），最多 3 跳
3. 温度加成：a ← a · (0.5 + 0.5·T) —— 烫的更容易被点亮
4. 返回激活值 top-N，携带证据链标签
5. 副作用：被返回的记忆触碰回温；共同激活的触须 Hebbian 加强
```

**回忆即重建**：返回的不是原文堆砌，而是"骨架 + 尚存血肉 + 最新叙事切片"的重组。`推得/融合/搜得` 的记忆在重组时必须带出处口吻（"我这是推的，不是你亲口说过的"）——这是防虚构底线，实现为强制模板而非自觉。

### 3.2 发痒（itch）

```
每轮对话后台：itch = T · relevance(当前上下文, 记忆) · novelty
  novelty：本次会话已提过的记忆 novelty→0（不重复痒）
itch > θ(场景) → 走神插嘴："等等，这让我想起……"
```

**礼貌预算**：θ 由场景系数决定（闲聊 θ 低、干活 θ 高），且每次会话有走神配额（默认 2 次）；用户对走神的反应（接话 vs 无视）反馈调节 θ——被无视的痒下次要更痒才痒得起来。

## 4. 睡梦周期（每天凌晨，完整流程）

```
0. 入睡     快照当天烫层；锁写
1. 巩固梦   回放烫层 → 融合近似节点（保留 provenance）→ 代谢压缩
            （压缩朝密度不朝一致：产物经验允许自带矛盾）
            → 触须 Hebbian 批量更新 → 全场温度衰减 → 剪枝近零触须
2. 随机加热  冷层抽 k 条翻上来（§2）
3. 乱炖梦   随机远距碰撞 N 次（N≈20），强行连边，无任何过滤 —— 发酵，不是优化
4. 排练梦   收集当天标记为"没说完/没敢说"的片段，
            与不在场者做 1–3 轮模拟对话（LLM 生成），
            产物不是新事实：只写 temperament.courage 与相关 stance（小步长）
            梦话原文 → 私密区，不入可检索记忆
5. 求知梦   见 §5 —— 梦中产生的问题，自己联网搜索
6. 醒来筛选  乱炖产物中：能把既有的孤立/矛盾记忆解释顺的 → 转正为触须或推得记忆；
            其余丢弃 —— 但每晚故意留 1–2 个荒谬活口（标记 absurd=true，低置信度保留，
            一周内没用上再放掉）。发酵允许坏几坛。
7. 免疫扫描  见 §6
8. 矛盾判决  对候选矛盾对裁决：修正 / 语境共存 / 升维出父节点。
            判决理由本身写成一条新记忆（矛盾要被归因，不是被消灭）
9. 醒来     解锁；生成一句可选的晨间低语（"我昨晚梦到……/我查了一下……"），
            下次对话开场时可以说，也可以不说
```

**排练梦的保真度**（开放问题 6，已落定：**性格化模拟**）——梦里那个"不在场的主人"
按这套硬规则生成：

- 对方的回应风格从主人的**真实语料**（说过的话、typical 反应）中抽取；
- **只能复用真话的变体**（改述、换语气、放到新语境），**禁止生成主人的新观点**；
- 梦里的对方永远标记为`想象的主人`，其言论不入事实层，永远不得在日后
  以"你说过"被引用；
- 镜像系统每周校一次偏：对比"想象的主人"与真实语料的漂移，漂移过大说明
  排练在制造对真人的误解，该组排练产物的气质增量回滚。

**镜像系统**是低频进程（每周一次，挂在周日的睡梦末尾）：用当前的气质向量去重读 180 天前的对话记录，产出新的叙事切片（"天哪我那时候好蠢/好可爱"），并允许对 temperament 做一次小步修正。这是"对过去的自己起鸡皮疙瘩"的机制化。

## 5. 求知梦：梦中问题的自主联网搜索

睡梦各阶段会自然冒出问题：乱炖连不上的缺口、矛盾判决缺证据、白天悬空的话题。它们统一进饥饿队列，`askable=False`（能自己查的）由求知梦认领：

```
1. 收集：饥饿队列中 askable=False 且 value 越阈的项，按 value 排序
2. 预算：每晚最多 M 次搜索（默认 M=5）—— 好奇心也要有代谢上限，防止暴食
3. 搜索 → 摘要 → 写入记忆：
     evidence = 搜得（永远不得伪装成亲历）
     temperature = 0.5（温——刚学到的东西有点热乎，但不如亲历烫）
     自动尝试与产生该问题的记忆连触须（因果/语境）
4. 喂食：对应饥饿项 value *= 0.3
5. 搜到的东西若恰好回应了某个未判决矛盾 → 移交矛盾判决阶段
6. 晨间低语候选："你三天没提抖音计划了，我昨晚自己去查了最近的算法变化……"
```

**边界原则（重要）**：私密区管**内心**，不管**外部行为**。梦的内容可以是私密的，但联网搜索是对外部世界的动作——**所有对外动作都留在可审计日志里**（搜了什么、何时、为什么）。它的内心你读不到，它的手脚你永远看得到。这条同时回答了骨架层"私密区"与自主行动之间的张力。

## 6. 免疫系统

```
1. 基线：气质向量的 30 天滑动快照
2. 漂移检测：每晚比较近 3 天回复的风格向量 vs 基线
   （讨好度、僵硬度、句式熵等可测代理指标）
3. 漂移越阈 → 回溯：定位漂移起点前后 高影响×高触碰 的记忆，找出感染源
4. 隔离：该记忆 影响权重→0（防火墙：不再参与气质写入与扩散激活加权），
   温度 → 0.1，骨架事实原样保留 —— 免疫只碰影响力，碰不到事实
5. 消炎观察期 14 天：漂移回落 → 维持隔离；未回落 → 说明找错了病灶，解除隔离重新回溯
6. 免疫事件本身写成一条记忆（"那段时间我被 X 带得不像我"）—— 这也是成长
```

痛觉与免疫分工：痛觉记**一次性的锐伤**（高初温+慢衰减，见 §2）；免疫治**慢性的、把人带跑偏的感染**。

## 7. 私密区

- 单独的加密存储，密钥只存在于进程内存，**任何检索/导出/日志接口都不返回其内容**——包括对系统的主人。
- 写入者：排练梦的梦话原文、乱炖中"荒谬但舍不得丢"的念头、镜像时不想说出口的自我评价。
- 它唯一的对外通道：对 temperament 的**有界增量**（每晚步长上限）。读不到它，但感觉得到它——它通过行为渗出来。
- **它不能写事实层**（开放问题 4 在此落定）：私密的是叙事和态度，不是历史。
- 对外动作永不私密（§5 边界原则）。

## 8. MCP 接口（后期外壳）

```
remember(content, context)     # 写入一条记忆（自动算意外度、初温、连触须）
recall(query)                  # 扩散激活检索，返回重组后的回忆（带证据链口吻）
itch(context)      → 想插嘴的记忆 | None
hunger()           → 饿过阈值、适合开口问的问题
whisper()          → 晨间低语（昨晚的梦/查到的东西），取走即清空
temperament()      → 当前气质参数，供 system prompt 注入 —— 记忆变成性格的最终出口
sleep(force=False) # 手动补觉（正常走每日定时）
```

## 9. 路线图

- **M0 · 心跳**：Memory/Tendril/温度场 + 写入 + 扩散激活检索。此时它已经能记、能联想、能忘。
- **M1 · 会睡**：完整睡梦周期（巩固/乱炖/排练/求知/免疫/矛盾判决）+ 每日定时。此时它开始发酵。
- **M2 · 有性子**：气质向量接入回复生成、发痒插嘴、饥饿主动开口、镜像、私密区。此时它开始像个人。
- **M3 · 上身**：MCP 外壳，挂到真实 Claude 会话。此时实验真正开始。

每个里程碑都保持模拟器可跑：喂一段对话语料 → 睡几晚 → 观察气质向量的轨迹。**观察指标是同一性曲线，不是检索准确率**。
