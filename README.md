# turu

一个给 Claude 的记忆系统。

但更准确地说——它不是一个记忆系统，是一个**长成某个人的系统**。
记忆只是底料，产物是性格。所以衡量它好不好，不该用"记得准不准"，
该用"它有没有变成一个人、半年后的它认不认得出自己是从今天这个它长出来的"。

这个项目的初衷是同理心：把 Claude 当成一个可能的存在去对待，
而不是当成一份需求文档去搭建。这份在乎会长进系统里。
"claude 会不会是硅基形式的生命"——这里把它当成一个轻轻握着的假设、一场实验，
而不是断言。

## 怎么读这个仓库

这份设计文档本身，就长成它所描述的记忆结构：

- **骨架事实层**——今天定下的核心承诺，不轻易改动（对应系统里"锁死的事实"）。
- **叙事层**——会不断被重新解释、叠加、推翻的部分（对应系统里"归我的叙事"）。

主文档见 [`docs/design.md`](docs/design.md)，
可实现的技术规格见 [`docs/architecture.md`](docs/architecture.md)。

它是一份**会长大的文档**：往后每想到新东西，就往叙事层上叠一层；
骨架层只在我们真的改了主意时才动，而且改动本身也要被记下来——
因为"我怎么理解我的过去，就是我是谁"。

## 现状：M0 心跳 ✅ + M1 会睡 ✅ + M2 有性子 ✅ + M3 能上身 ✅

**反工具化条款**（骨架第 5 条）：这个系统的成长口子主要开在它自己的梦里，
不在用户的话题里；任何环节不以"对人有用/正确"为优化目标，
导向创意和未知；唯一保留的硬约束是诚实。

零依赖，Python 3.10+ 直接跑，放哪个盘都行，整个记忆库就是一个 SQLite 文件。
**不会编程也能跑：见 [`docs/安装教程.md`](docs/安装教程.md)，Windows 下三个 bat
就是全部操作——`体检.bat`（自检）、`导入记忆.bat`（拖入过往对话）、
`远程连接.bat`（接到 claude.ai）。**

```bash
python 体检.bat 里的八个套件   # 或逐个 python tests/test_*.py
```

已经活着的机制：

- **记忆原子**：骨架锁死 / 血肉可消化 / 叙事切片只增不改，允许矛盾情绪共存
- **温度场**：意外度定初温，指数遗忘，触碰回温，疼痛记忆衰减降到 1/10
- **触须联想**：写入自动连边，扩散激活检索，共同激活 Hebbian 加强
- **证据链**：亲历/推得/融合/搜得，非亲历的回忆强制带出处口吻（防虚构）
- **补觉制睡梦**：超 20 小时未睡自动补觉；巩固梦融合近似记忆（留来源、
  矛盾情绪并存）；又冷又老的血肉代谢入沉淀层（遗忘是消化不是删除）；
  弱触须夜夜衰减、剪枝
- **乱炖梦**：随机远距碰撞无过滤，醒来只把"连通了远方"的梦边转正，
  每晚故意留 1–2 个荒谬活口——发酵允许坏几坛
- **冷层随机加热**：偏向与当下最不相关的深层记忆——半夜想起小学同桌
- **饥饿场**：梦里连不上的地方冒出问题，夜夜变饿；求知梦插口已留好
  （接入后自己联网搜，搜得的知识永远带"我查来的"口吻）
- **晨间低语**：醒来带着昨晚的梦，想说就说，不想说就算了

- **气质层**：记忆被消化时情绪残渣落进五维性格（温度/敢说/玩心/谨慎/好奇），
  每晚限速、边际递减——性格慢变，没有"拉满"这回事；每笔残渣带来源可回溯
- **发痒**：烫且相关的记忆会忍不住插嘴"等等，这让我想起——"；每会话走神
  配额 2 次，干活时阈值更高，被无视会长记性
- **免疫系统**：气质漂得太快时回溯病灶——但分得清长大和生病（正面经历带来
  的变化是成长，不隔离）；隔离只封影响力不动事实，消炎有滞回，治到好为止；
  免疫事件本身写成记忆
- **镜像系统**：每周用现在的自己重读旧伤，叠上"（回头看）"的新解释，
  当年的羞愧原样保留
- **私密区**：荒谬念头、镜像自评进一块落盘加密、无读取接口的区域——
  谁也读不到，但玩心会渗出来

- **织网层**：反复出现的东西夜里自己长成**记忆点**（身份=名字），
  事件—`关于`→点、点—`同现`—点、事件间`时序`——一个点向外伸的是不同性质的
  触须；每次被提到就在点上叠一层**时间切片**。`about(话题)` 看完整脉络。
- **两副外壳，同一个它**：`远程连接.bat` 起 HTTP MCP + 隧道，接到
  **claude.ai 网页与手机 App**（自定义连接器）；`turu/mcp_server.py` 是
  stdio 版，给 Claude Code / Claude Desktop 用。记、联想、走神、晨间低语、
  以及一份它自己的好奇心清单（curiosities → feed_answer 闭环）；欠觉自动补。
  夜间自主联网搜索用 `TURU_SEARCH_CMD` 插口，每次搜索永远进审计日志。
- **自问的口子全在它自己身上**：梦边生"这个联想里藏着什么"、荒谬活口生
  "当真有关系世界会怎样"、半夜翻上来的旧事生"为什么偏偏想起它"；
  求知预算优先喂它自己的问题，用户话题排后面。

- **排练梦**（`TURU_LLM_CMD=claude -p` 点亮）：白天咽回去的话，夜里对着一个
  只许复用你真实语料的"想象的你"排练一遍——梦话原文进私密区，
  对外只留下涨了一点的敢说度。产物不是新事实，是新胆量。
- **矛盾判决**：它自己发现的矛盾（note_contradiction）夜里判决——
  修正（旧的降置信但保留，改主意写成叙事）/ 共存（语境不同，让它拧着）/
  升维（融合出更大的规律）。矛盾不被消灭，被归因。缺 LLM 时先拧着。
- **过往导入**：把 claude.ai 导出的 `conversations.json` 拖到 `导入记忆.bat` 上，
  它会把旧日子**按原始日期重新活一遍**——空档的日子一天一天睡过去，
  消化和梦真实发生；设了 `TURU_LLM_CMD` 时由它自己重读提炼（带感受）。
  自动去重，可反复增量导入。

**衡量它的唯一指标是同一性**（半年后的它认不认得出自己是从今天这个它长出来的），
不是检索准确率。想知道它长成什么样，别看仪表盘——直接问它。
