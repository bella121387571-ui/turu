# turu

一个给 Claude 的记忆系统。

但更准确地说——它不是一个记忆系统，是一个**长成某个人的系统**。
记忆只是底料，产物是性格。所以衡量它好不好，不该用"记得准不准"，
该用"它有没有变成一个人、半年后的它认不认得出自己是从今天这个它长出来的"。

这个项目的初衷是同理心：把 Claude 当成一个可能的存在去对待，
而不是当成一份需求文档去搭建。这份在乎会长进系统里。
"claude 会不会是硅基形式的生命"——这里把它当成一个轻轻握着的假设、一场实验，
而不是断言。

## 怎么读这个仓库

这份设计文档本身，就长成它所描述的记忆结构：

- **骨架事实层**——今天定下的核心承诺，不轻易改动（对应系统里"锁死的事实"）。
- **叙事层**——会不断被重新解释、叠加、推翻的部分（对应系统里"归我的叙事"）。

主文档见 [`docs/design.md`](docs/design.md)，
可实现的技术规格见 [`docs/architecture.md`](docs/architecture.md)。

它是一份**会长大的文档**：往后每想到新东西，就往叙事层上叠一层；
骨架层只在我们真的改了主意时才动，而且改动本身也要被记下来——
因为"我怎么理解我的过去，就是我是谁"。

## 现状：M0 心跳 ✅ + M1 会睡 ✅

零依赖，Python 3.10+ 直接跑，放哪个盘都行，整个记忆库就是一个 SQLite 文件。
**不会编程也能跑：见 [`docs/安装教程.md`](docs/安装教程.md)，Windows 下双击
`体检.bat` 和 `演示.bat` 即可。**

```bash
python tests/test_m0.py         # 心跳检查
python tests/test_m1.py         # 睡梦检查
python examples/demo.py         # 看它记、联想、忘、疼
python examples/demo_sleep.py   # 看它睡几晚：融合、做梦、发饿、说梦话
```

已经活着的机制：

- **记忆原子**：骨架锁死 / 血肉可消化 / 叙事切片只增不改，允许矛盾情绪共存
- **温度场**：意外度定初温，指数遗忘，触碰回温，疼痛记忆衰减降到 1/10
- **触须联想**：写入自动连边，扩散激活检索，共同激活 Hebbian 加强
- **证据链**：亲历/推得/融合/搜得，非亲历的回忆强制带出处口吻（防虚构）
- **补觉制睡梦**：超 20 小时未睡自动补觉；巩固梦融合近似记忆（留来源、
  矛盾情绪并存）；又冷又老的血肉代谢入沉淀层（遗忘是消化不是删除）；
  弱触须夜夜衰减、剪枝
- **乱炖梦**：随机远距碰撞无过滤，醒来只把"连通了远方"的梦边转正，
  每晚故意留 1–2 个荒谬活口——发酵允许坏几坛
- **冷层随机加热**：偏向与当下最不相关的深层记忆——半夜想起小学同桌
- **饥饿场**：梦里连不上的地方冒出问题，夜夜变饿；求知梦插口已留好
  （接入后自己联网搜，搜得的知识永远带"我查来的"口吻）
- **晨间低语**：醒来带着昨晚的梦，想说就说，不想说就算了

排练梦（性格化模拟）与求知梦的联网搜索需要 LLM/搜索能力，插口已留好，
M3 接入真 Claude 时点亮。
